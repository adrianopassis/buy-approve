# BuyApprove

BuyApprove is a web application for managing business purchases.

The main goal of this project is to help companies organize their purchasing process, from creating purchase requests to approving orders and managing suppliers.

This is a personal study project where I can practice backend and frontend development, database management, and software architecture.

## Technologies

- Java 21
- Spring Boot
- Angular
- PostgreSQL
- Spring Data JPA
- Spring Security
- Flyway
- Docker
- Gradle

## Main Features

- Company and user management
- Supplier management
- Purchase requests
- Purchase approvals
- Supplier quotations
- Purchase orders
- Purchase tracking

## Architecture

The project follows a modular monolith architecture, with the backend developed using Java and Spring Boot, the frontend using Angular, and PostgreSQL as the database.

## Project Status

This project is currently under development.

The first step is to configure the development environment and implement company management.
